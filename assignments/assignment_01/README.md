**Status:** Instructor draft — edit before releasing to students.

## Objective

Demonstrate that you can load a dataset, inspect its structure, select columns, and filter rows using Pandas.

## Suggested tasks

1. Load the instructor-provided CSV dataset with `pd.read_csv()`.
2. Display the first five records with `head()`.
3. Show the number of rows and columns (`shape`).
4. Inspect column names and data types (`columns`, `dtypes`).
5. Use `info()` to identify any missing-value information.
6. Use `describe()` to summarize numerical columns.
7. Select one column as a Series and two columns as a DataFrame.
8. Filter rows using a numerical condition and a text condition.
9. Add brief comments explaining your observations.
