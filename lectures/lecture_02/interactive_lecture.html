B. Structured, semi-structured and unstructured data

The type depends on how the information is organized, not on the file extension. A .txt file can hold a perfect table, and a .json file can hold deeply nested data.

Structured data has rows, columns and a fixed structure. Every row has the same fields.

numeric columntext (categorical) columnTrue/False columnmissing value

Semi-structured data has labels (keys) but no fixed table shape. Records can have nested objects and lists.

Unstructured data has no built-in rows and columns. We must extract information before analysis.

CSV, Excel, JSON & Parquet

Four common ways to store tabular data.

CSV delimitersExcel sheetsJSON nestingParquet columns

CSV — Comma-Separated Values

CSV is plain text. The first line is usually the header. Each next line is a row. A delimiter separates the values.

The file uses:

Pandas reads with:

customers.csv (text)

      
Parsing preview 

    

    

  

  
Type inference: CSV stores only text. Pandas guesses each column type. A code like 00123 may be read as the number 123, and a missing value (empty field) becomes NaN. CSV does not store type information.

  
Instructor cue

Excel — workbooks for humans

  
An Excel file is a workbook with one or more sheets. It can have formulas, colors and merged cells. This is great for people, but extra decoration can make automatic reading harder.

  
Conceptual multi-sheet workbook: store_demo.xlsx (illustrative only; not created by the starter code). The hands-on customers.xlsx created in Chapter 4 contains only Sheet1. The sheet-selection examples require a workbook that actually contains those sheets.

    

    
Without sheet_name, Pandas reads the first sheet. A “Total” row typed under the data would be read as one more data row.

Parquet — columnar binary storage

  
Parquet is a binary format. It stores data column by column, keeps schema (column names and types) and supports compression.

Text filtering

  
df[df["city"] == "Amman"]

  

  
Text comparison is exact and case-sensitive.

  
"Amman" ==


  
Multiple conditions

  
df[
    (df["age"] > 25) &
    (df["salary"] > 1000)
]

  

    
& AND — both conditions True
| OR — at least one True
~ NOT — flips True / False

  

  
Always put parentheses around each condition. Do not use Python and / or between Series: Pandas raises a ValueError (“truth value of a Series is ambiguous”).

  

    
Adf["age"] > 25Bdf["salary"] > 1000

Chapter 7 recap
  • A condition makes a True/False Series. df[mask] keeps the True rows.
  • Use & | ~ with parentheses. Text matching is case-sensitive. NaN never passes > or ==.
